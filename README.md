# Sampat Mishra – Portfolio

Static site: no build step needed.

- `index.html` – the whole site (portfolio, View my life, View CV)
- `images/` – all photos, logos and the hero character
- `Sampat_Mishra_CV.pdf` – the downloadable CV

## Deploy
GitHub: upload the contents of this folder to a new repository (keep the folder structure).
Vercel: import the repository, framework preset "Other", leave build command and output directory empty.
